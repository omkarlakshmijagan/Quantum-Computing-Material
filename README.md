## Course topics

The material introduces core mathematical and computational foundations of quantum information, including:

- **Quantum states and mathematical foundations:** qubits, Hilbert spaces, bra–ket notation, inner products, pure and mixed states, and density matrices.
- **Quantum-state visualization and operations:** Bloch sphere, quantum gates, and state transformations.
- **Quantum algorithms:** Deutsch's algorithm, Deutsch–Jozsa algorithm, Grover's search algorithm, and Quantum Fourier Transform (QFT).
- **Quantum error correction:** introductory concepts and supporting course notes.

For the exact unit-wise syllabus and sequence, refer to the linked unit notes and presentations.

## How to use

**Read online:** Open the relevant folder above and select a PDF or Markdown document. GitHub can preview many PDF and Markdown files directly; download PowerPoint or Word files if your browser does not preview them.

**Download everything:** Select **Code → Download ZIP** from the repository page, or clone the repository:

```bash
git clone https://github.com/omkarlakshmijagan/Quantum-Computing-Material.git
cd Quantum-Computing-Material
```

**Recommended study sequence:**

1. Read the lecture slides for the current unit.
2. Study the corresponding PDF notes and derive key results by hand.
3. Review the dedicated algorithm and error-correction documents where relevant.
4. Practice the Mid-I or Mid-II question bank.
5. Compare your solutions with the provided answer material.

> **Note:** This is primarily a collection of educational documents, not a software package. No installation of quantum programming frameworks is required to access the material. A PDF reader and software compatible with `.pptx`, `.doc`, and `.docx` files may be useful.
